# Resource-Allocation-Model
Optimization model for a $500K construction project using Excel Solver and scenario analysis to improve resource allocation and reduce projected delays by 20%.

# Overview
This project develops a resource allocation optimization model for a simulated $500K construction project operating under tight scheduling constraints. The goal was to analyze trade-offs between cost, labor, and time to improve project efficiency and reduce delays. Using Excel Solver and scenario analysis, the model evaluates multiple allocation strategies and recommends an optimized plan that reduces projected delays by 20%.

# Problem Statement
Construction projects often face inefficiencies due to poor resource allocation, leading to delays and increased costs. This model simulates real-world constraints to identify optimal allocation strategies under limited resources and time pressure.

# Objectives
Optimize allocation of labor and resources under budget constraints
Minimize project delays while maintaining cost efficiency
Evaluate multiple scenarios to support data-driven decision making

# Methodology
Defined project constraints (budget, labor availability, timeline)
Built optimization model using Excel Solver
Tested multiple allocation scenarios
Compared outcomes based on cost vs. delay trade-offs
Selected optimal solution based on efficiency metrics

# Key Results

Improved resource utilization efficiency
Demonstrated measurable trade-offs between cost and time
